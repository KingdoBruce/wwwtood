平时注册网站、测试工具或体验在线服务时，经常需要填写邮箱地址。

如果每次都使用自己的常用邮箱，时间久了很容易收到大量广告邮件、推广信息，甚至还可能因为网站安全性不足，导致邮箱地址被泄露。

遇到这种情况，临时邮箱就是一个比较实用的解决方案。

今天分享一个开源项目——**Cloud Mail**。它可以借助 [Cloudflare](/tags/cloudflare/) 的相关服务，搭建一套属于自己的临时邮箱系统，不需要购买传统服务器，部署成本较低，适合个人用户和开发者使用。

![QQ20260727-122753](/uploads/2026/07/QQ20260727-122753-1939fbbb.jpg)

## Cloud Mail 是什么？

Cloud Mail 是一个基于 Cloudflare 生态搭建的开源临时邮箱项目。

部署完成后，你可以使用自己的域名创建临时邮箱地址，用来接收验证码、注册邮件和测试邮件，从而减少真实邮箱被公开的次数。

与公共临时邮箱网站相比，自建服务的邮箱域名和后台都由自己管理，使用起来也更加灵活。

## 它可以解决哪些问题？

### 减少垃圾邮件

注册一些临时使用的网站时，可以直接使用临时邮箱，不必填写自己的主邮箱。

这样即使网站后续发送大量推广邮件，也不会影响日常使用的工作邮箱或私人邮箱。

### 降低邮箱泄露风险

很多网站在注册时都会收集用户邮箱，但并不是所有平台都值得完全信任。

使用临时邮箱，可以减少常用邮箱在不同网站之间反复暴露，降低被收集、出售或泄露的可能性。

### 接收验证码和注册邮件

Cloud Mail 可以用于接收常见的邮件内容，例如：

* 网站注册验证码
* 账号激活邮件
* 一次性登录链接
* 测试通知邮件
* 开发环境验证邮件

对于只需要短时间接收邮件的场景来说，临时邮箱会更加方便。

## 为什么选择 Cloudflare 部署？

传统邮件系统通常需要购买服务器、配置环境，还要处理端口、防火墙、系统维护和安全更新等问题。

Cloud Mail 则采用更加轻量的部署方式，结合 Cloudflare 的 Serverless 服务和全球网络能力，可以减少服务器维护工作。

它的主要特点包括：

* 不需要单独购买传统服务器
* 部署和维护成本较低
* 可以绑定自己的域名
* 适合个人项目和开发测试
* 可以体验 Cloudflare Serverless 架构

对于已经在使用 Cloudflare 托管域名的用户来说，部署过程会更加顺手。

## Cloud Mail 适合哪些人？

这个项目比较适合以下使用场景：

* 经常注册不同网站的用户
* 不愿意公开真实邮箱的人
* 需要接收一次性验证码的用户
* 测试邮件注册和验证功能的开发者
* 想减少主邮箱垃圾邮件的人
* 喜欢研究 Cloudflare 和 Serverless 的用户
* 想搭建个人邮箱工具的开源项目爱好者

## 开源项目有什么优势？

Cloud Mail 的源代码是公开的，可以直接查看项目实现方式。

有开发能力的用户，还可以根据自己的需求修改功能，例如调整页面样式、增加邮箱管理功能、优化邮件列表，或者加入访问权限控制。

相比完全依赖第三方临时邮箱平台，开源项目的透明度更高，也更适合长期学习和二次开发。

## 使用时需要注意什么？

临时邮箱适合注册测试、接收验证码和处理非重要邮件，但不建议用于保存关键账号。

例如银行账户、支付平台、企业后台、域名注册商或重要社交账号，仍然建议绑定长期稳定的常用邮箱，并开启双重验证。

另外，临时邮箱并不等于完全匿名。部署和使用过程中，仍然需要注意域名安全、后台权限以及 Cloudflare 账户的保护。

## 总结

Cloud Mail 提供了一种轻量化的临时邮箱搭建方案。

它可以帮助用户减少真实邮箱的暴露次数，降低垃圾邮件骚扰，同时又不需要购买和维护传统服务器。

如果你经常注册网站、测试邮件功能，或者想体验 Cloudflare Serverless 项目，那么 Cloud Mail 是一个值得尝试的开源工具。

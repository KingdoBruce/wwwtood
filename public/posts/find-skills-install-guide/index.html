Skills 太多不知道装哪个？先用 Find Skills 帮你筛选

接触 Claude Code、Codex、Cursor 或其他 AI Agent 一段时间后，很多人都会遇到同一个问题：

可安装的 Skills 越来越多，但真正适合自己的却很难找。

看到别人推荐测试 Skills、SEO Skills、前端设计 Skills、亚马逊选品 Skills，很多新手的第一反应是全部收藏，或者看到一个就安装一个。

最后工具箱越来越大，真正使用的可能只有两三个。

与其花时间在 GitHub 和 Skills.sh 里逐个翻找，不如先安装一个专门帮助你寻找 Skills 的 Skills：Find Skills。

Find Skills 是什么？

Find Skills 的代码名称是 find-Skills，由 Vercel Labs 的 Skills 项目提供。

它不是用来替你写代码、做选品或制作视频的业务型 Skills，而更像一个 AI Skills 导航员。

它主要做三件事：

  1. 根据你的实际任务寻找相关 Skills；
  2. 对搜索结果进行初步筛选；
  3. 提供 Skills 的用途、来源和安装命令。

你只需要把需求说清楚，它就会帮助你缩小范围，而不是让你面对一长串不知道该怎么选择的 Skills。

为什么建议先安装 Find Skills？

真正的问题通常不是没有 Skills，而是 Skills 太多。

Skills.sh 是一个开放的 Agent Skills 目录，里面收录了大量可复用能力。Skills 可以理解为一组面向特定任务的操作说明、脚本和相关资源，用来教 AI Agent 按照相对固定的流程完成工作。

但 Skills 数量增加后，也会带来三个问题：

  • 名称相似，不知道哪个更适合；
  • 来源不同，质量差距较大；
  • 安装太多后，管理和维护成本上升。

因此，Find Skills 的价值不只是“帮你搜索”，而是先理解任务，再帮助你判断哪些结果更值得进一步查看。

Find Skills 是怎么寻找 Skills 的？

根据其官方说明，Find Skills 通常会按照以下流程工作。

第一步：拆解你的真实需求

它会先判断：

  • 你属于哪个领域；
  • 你具体想完成什么任务；
  • 这个任务是否可能已经有成熟的 Skills。

例如，“我想做亚马逊”范围太大。

更有效的表达是：

帮我寻找一个适合亚马逊产品研究的 Skills，重点关注关键词、竞品分析、市场需求和广告数据。

需求越具体，搜索结果通常越准确。

第二步：先查看热门 Skills

Find Skills 会先检查 Skills.sh 排行榜，看看相关领域是否已经存在安装量较高、使用较广的 Skills。

热门不代表一定适合你，但通常意味着有更多用户使用和验证，可以作为第一轮筛选依据。

第三步：使用关键词继续搜索

如果排行榜中没有合适的结果，它会使用 Skills CLI 继续搜索，例如：

1

npx Skills find amazon product research

Skills CLI 也支持直接按关键词搜索：

1

npx Skills find typescript

还可以限定 GitHub 用户或组织：

1

npx Skills find react --owner vercel

第四步：核对 Skills 的质量

Find Skills 不应该只根据搜索结果名称进行推荐，还会重点查看：

  • 安装量；
  • 作者或组织来源；
  • GitHub 仓库星标；
  • 项目是否持续维护；
  • Skills 的实际用途；
  • 是否与当前任务匹配。

官方指南建议优先考虑安装量较高、来源可信的 Skills；安装量很少、来源陌生或仓库维护不足的项目，则需要更加谨慎。

Find Skills 安装命令

可以使用下面的命令安装 Vercel Labs 提供的 find-Skills：

1

npx Skills add vercel-labs/Skills --Skills find-Skills

在支持指定 Agent 的环境中，也可以明确选择安装目标。例如安装到 Claude Code：

1

npx -y Skills add vercel-labs/Skills --Skills find-Skills --agent claude-code

执行方法很简单：

  1. 打开终端；
  2. 粘贴安装命令；
  3. 按下回车；
  4. 根据终端提示完成安装。

需要注意的是，不同 Agent 和 Skills CLI 版本的安装路径或参数可能有所区别。安装前可以先查看项目最新说明。

安装后怎么使用？

安装完成后，不需要记住复杂命令，可以直接使用自然语言描述需求。

例如：

帮我寻找一个用于前端自动化测试的 Skills，优先推荐来源可信、安装量较高并且仍在维护的项目。

或者：

帮我找一个适合独立站 SEO 内容分析的 Skills，需要支持关键词研究、竞品分析和内容缺口检查。

还可以进一步增加筛选条件：

请先说明每个 Skills 的用途、作者来源、安装量、GitHub 仓库情况和安装命令，不要直接安装，等我确认后再操作。

这样做可以避免 AI 搜到结果后立即安装，也方便你先比较不同选项。

哪些人适合使用 Find Skills？

Find Skills 并不只适合程序员。

程序员

可以寻找：

  • 自动化测试 Skills
  • 代码审查 Skills
  • Git 提交规范 Skills
  • React 或 Next.js 优化 Skills
  • 部署和排错 Skills

跨境电商卖家

可以寻找：

  • 亚马逊选品 Skills
  • 关键词研究 Skills
  • 竞品分析 Skills
  • Listing 优化 Skills
  • 广告数据分析 Skills

内容创作者

可以寻找：

  • 视频脚本 Skills
  • 标题生成 Skills
  • SEO 内容优化 Skills
  • 社交媒体分发 Skills
  • 字幕和内容整理 Skills

个人网站站长

可以寻找：

  • 技术 SEO 检查 Skills
  • 网站性能优化 Skills
  • 结构化数据 Skills
  • 内容审查 Skills
  • Google Search Console 分析 Skills

核心原则只有一个：

不要按照 Skills 的名字搜索，而要按照自己准备完成的任务搜索。

安装第三方 Skills 前要注意什么？

Find Skills 可以帮你缩小范围，但不能代替最终的安全判断。

安装之前，建议至少检查以下内容：

  1. 查看作者来源

优先考虑官方组织、知名开发者或长期维护的开源仓库。

  1. 阅读 Skills.md

确认它会执行哪些步骤、调用哪些命令，以及是否会修改本地文件。

  1. 检查脚本和依赖

如果 Skills 带有 Shell、Python、JavaScript 脚本，应先查看脚本内容，不要直接运行来源不明的代码。

  1. 检查更新时间和 Issue

长时间没有更新、存在大量未处理问题的项目，需要谨慎安装。

  1. 不要一次安装几十个

先根据当前任务安装两三个真正需要的 Skills，使用一段时间后再决定是否保留。

Find Skills 和 npx Skills find 有什么区别？

两者都可以帮助你搜索 Skills，但使用方式不同。

npx Skills find 是直接在终端中搜索：

1

npx Skills find seo

Find Skills 则会先理解你的自然语言需求，再决定搜索哪些关键词，并帮助你整理和比较结果。

简单理解：

  • npx Skills find 是搜索工具；
  • Find Skills 是帮助你使用搜索工具的导航规则。

对于已经知道准确关键词的人，直接使用命令会更快。

对于不知道该搜什么、也不知道如何判断质量的新手，Find Skills 更容易上手。

我的使用建议

不要一开始就安装几十个 Skills。

更合理的顺序是：

  1. 先安装 Find Skills；
  2. 明确当前准备完成的任务；
  3. 让它推荐两到三个候选 Skills；
  4. 检查来源、安装量、仓库和脚本；
  5. 只安装真正适合当前工作的项目；
  6. 定期删除长期不用的 Skills。

Find Skills 节省的不只是搜索时间。

更重要的是，它可以减少无效安装，让你的 AI Agent 工具箱保持轻量，并把注意力重新放回真正需要完成的任务上。

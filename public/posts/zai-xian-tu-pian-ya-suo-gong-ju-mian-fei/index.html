需要减小图片体积，又不想把私人照片或工作素材上传到第三方服务器，可以试试这款免费的在线图片压缩工具。

它支持 JPG、PNG 和 WebP 格式，可一次处理多张图片，并允许自定义压缩质量、最大宽度和输出格式。所有压缩操作都在浏览器本地完成，图片不会上传到服务器。

工具地址

打开在线图片压缩工具

主要功能

  • 支持 JPG、PNG、WebP 图片
  • 支持一次批量压缩多张图片
  • 自定义图片压缩质量
  • 按最大宽度调整图片尺寸
  • 转换 JPG、PNG、WebP 输出格式
  • 压缩完成后直接下载
  • 适配电脑和手机浏览器
  • 无需注册或安装软件

适合哪些场景

这款工具比较适合以下用途：

  • 压缩网站文章和博客配图
  • 减小 WordPress、Hugo 等网站的图片体积
  • 优化商品图、封面图和社交媒体图片
  • 将 JPG 或 PNG 转换为 WebP
  • 在上传图片前降低文件大小
  • 处理不方便上传到第三方服务器的图片

图片体积减小后，可以降低网页传输流量，并有助于改善页面加载速度。

如何使用

  1. 打开图片压缩工具。
  2. 将图片拖入上传区域，或点击选择本地图片。
  3. 设置压缩质量、最大宽度和输出格式。
  4. 点击“开始压缩”。
  5. 查看压缩前后的文件大小并下载图片。

整个过程都在当前浏览器中完成，不需要把图片发送到远程服务器。

压缩参数怎么设置

普通网站配图

建议将压缩质量设置为 70%—85%。通常可以明显减小文件体积，同时保持较好的视觉效果。

商品图和细节图

建议使用 80%—90% 的质量，避免纹理、文字和商品细节变得模糊。

图片尺寸过大

可以设置最大宽度，例如：

  • 博客正文图片：1200—1600 像素
  • 网站缩略图：600—900 像素
  • 社交媒体配图：按发布平台要求设置

如果原图宽度没有超过设定值，通常不需要再次放大。

转换为 WebP

WebP 通常适合网站配图，可以在保持较好画质的同时减小文件体积。但在替换网站原图前，应确认当前网站程序和目标平台支持 WebP。

隐私说明

图片读取、缩放、压缩和格式转换均由浏览器完成，不需要先上传至服务器。

不过仍建议在公共电脑上处理敏感图片后，及时关闭页面并删除下载记录。浏览器性能也会影响批量处理速度，超大图片或一次选择过多文件时，可能占用较多内存。

技术实现

该工具采用纯前端方式开发，不依赖后端图片处理服务。

主要使用：

  • HTML5
  • 原生 CSS
  • 原生 JavaScript
  • Canvas API

因为不需要数据库和服务器端运行环境，所以可以部署到 GitHub Pages、Cloudflare Pages 或其他静态网站托管平台。

浏览器支持

建议使用较新的浏览器版本：

  • Chrome 60+
  • Firefox 55+
  • Safari 11+
  • Edge 79+

旧版浏览器可能无法正常处理 WebP 格式或部分 Canvas API 功能。

部署到 GitHub Pages

  1. Fork 或克隆项目仓库。
  2. 打开 GitHub 仓库的 Settings。
  3. 进入 Pages 设置。
  4. 在部署来源中选择 main 分支。
  5. 目录选择 / (root)。
  6. 保存设置并等待 GitHub Pages 完成部署。

项目地址

  • 在线使用：https://img.tood.win
  • GitHub 项目：KingdoBruce/Image-compression

这是一个纯前端图片处理项目，适合个人站长、内容创作者和开发者直接使用，也可以自行部署和修改。

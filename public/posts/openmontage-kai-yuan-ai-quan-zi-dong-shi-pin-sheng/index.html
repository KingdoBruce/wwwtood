OpenMontage：开源 AI 全自动视频生产系统，从脚本到剪辑一条指令完成

OpenMontage 是一个开源的 Agentic AI 视频生产系统。它不是单纯的文生视频模型，而是将选题研究、脚本创作、素材生成、配音、字幕、音乐、剪辑和最终渲染组织成完整的视频生产流水线。

用户可以直接在 Claude Code、Cursor、GitHub Copilot、Windsurf 或 Codex 等 AI 编程助手中描述视频需求，OpenMontage 会根据任务选择合适的制作流程，并调用本地工具或云端 AI 服务完成视频制作。

OpenMontage 可以做什么？

例如输入下面的指令：

1

制作一条 60 秒的动画科普视频，主题是神经网络如何学习，需要中文旁白、背景音乐和字幕。

系统会依次处理：

  1. 搜索并整理主题资料；
  2. 生成视频方案和脚本；
  3. 拆分场景与镜头；
  4. 搜索或生成图片、视频素材；
  5. 生成旁白、字幕和背景音乐；
  6. 使用 Remotion 或 FFmpeg 完成剪辑与渲染；
  7. 检查画面、音量、字幕和视频文件是否正常。

它也支持使用 Archive.org、NASA、Wikimedia Commons 等公开素材源搜索真实视频片段，而不只是把静态图片做成缩放动画。

当前主要功能

根据 OpenMontage 官方仓库目前的介绍，项目包含：

项目 当前规模
视频生产流水线 12 条
视频制作工具 100+
Agent Skill 与制作知识文件 700+

现有流水线覆盖多种视频类型，包括：

  • 动画科普视频
  • 产品宣传片与电影预告片
  • 真人口播视频
  • 软件操作演示
  • 纪录片式素材混剪
  • 播客转短视频
  • 长视频批量切片
  • 视频翻译、配音与本地化
  • AI 画面与真实素材混合剪辑

每条流水线都会按照类似下面的结构运行：

1

资料研究 → 视频方案 → 脚本 → 分镜 → 素材 → 剪辑 → 合成

OpenMontage 的核心并不是某一个 AI 模型，而是让 AI Agent 阅读 YAML 流水线配置、Markdown 导演指令和工具说明，再调用对应的 Python 工具执行任务。

是否可以完全免费使用？

部分流程可以不配置付费 API。

例如，OpenMontage 可以使用本地语音工具、公开素材库、开源视频工具和 Remotion 制作基础科普视频或真实素材混剪。

但是，制作 AI 动画、电影预告片或高质量产品广告时，通常需要配置图片生成、视频生成、语音合成或音乐生成服务。最终费用取决于所使用的模型、视频长度和素材数量。

因此，它更准确的定位是：

可以使用免费和本地工具运行，也可以接入付费 AI 服务提高画面质量，而不是所有视频都能完全零成本生成。

系统提供费用预估、预算上限和付费操作确认功能，可以降低批量生成时意外产生高额 API 费用的风险。

安装要求

运行 OpenMontage 前需要准备：

  • Python 3.10 或更高版本
  • FFmpeg
  • Node.js 18 或更高版本
  • Claude Code、Cursor、Copilot、Windsurf 或 Codex 等可读取文件并执行命令的 AI 助手

基础安装命令：

1
2
3

git clone https://github.com/calesthio/OpenMontage.git
cd OpenMontage
make setup

安装完成后，用 AI 编程助手打开项目目录，再输入需要制作的视频内容即可。官方也提供了无需 API Key 的演示流程，适合先检查本地环境是否配置成功。

OpenMontage 是否真的不需要人工操作？

OpenMontage 可以自动执行大量重复工作，但并不等于整个过程完全不需要用户参与。

在正式生成素材或调用付费模型之前，系统可能会展示：

  • 视频创意方案
  • 使用的模型与服务商
  • 预计制作费用
  • 场景和素材预览
  • 渲染方案
  • 需要确认的创意选择

这些确认步骤可以避免生成方向错误、素材不符合预期，或者在没有注意的情况下产生 API 费用。

因此，更适合将 OpenMontage 理解为一个 由 AI Agent 驱动的视频生产工作台，而不是输入一句话后完全不可控的黑盒视频生成器。

适合哪些用户？

OpenMontage 比较适合：

  • 经常制作科普、教程或资讯视频的创作者；
  • 需要批量生产短视频的内容团队；
  • 希望把播客和长视频拆分成短内容的用户；
  • 需要自动生成字幕、配音和多语言版本的团队；
  • 熟悉 Codex、Claude Code 或 Cursor 的开发者；
  • 想研究 AI Agent 视频工作流的人。

对于只想偶尔制作一条简单视频、又不熟悉命令行和 API 配置的普通用户，在线剪辑工具可能更容易上手。

使用前需要注意

  1. 不是所有流程都完全免费

    本地工具和公开素材可以降低成本，但高级图片、视频和语音模型通常需要 API Key。

  2. 生成结果仍然需要审核

    AI 可能出现事实错误、字幕错误、素材不匹配或音乐版权来源不清等问题，正式发布前应人工检查。

  3. 公开素材不代表可以随意使用

    使用 Archive.org、Wikimedia Commons、Pexels 等来源时，仍需确认具体素材的授权范围和署名要求。

  4. 需要一定的本地环境配置能力

    用户需要安装 Python、Node.js 和 FFmpeg，并能够处理依赖安装或 API 配置问题。

  5. 注意开源许可证

    OpenMontage 当前采用 AGPL-3.0 许可证。修改项目并通过网络提供相关服务时，应先了解该许可证对源代码公开的要求。

总结

OpenMontage 的价值不只是“用 AI 生成一段视频”，而是把资料研究、脚本、分镜、素材、配音、字幕、剪辑和检查连接成一套可复用的自动化流程。

它适合希望提高视频生产效率、批量制作内容，或者想用 Codex、Claude Code、Cursor 构建 AI 视频工作流的用户。不过，高质量视频仍然需要合适的模型、素材审核和人工创意判断，不能简单理解为完全无人参与的一键出片工具。

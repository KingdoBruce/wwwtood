章节内容

制作 AI 漫剧，真正困难的通常不是生成一张图片，而是如何让剧情节奏、人物形象和镜头衔接保持一致。

目前 GitHub 上已经出现多套面向 Claude Code、Codex 等 AI Agent 的开源 Skills。虽然不同项目的命名并不完全相同，但核心流程基本可以归纳为三类：

  1. 剧本创作 Skill
  2. 图像资产 Skill
  3. 分镜制作 Skill

这三类 Skill 可以把小说或创意逐步转换为剧本、角色资产、分镜表和图像或视频提示词。

一、剧本创作 Skill

剧本 Skill 负责把小说、故事大纲或简单创意，整理成适合短剧和漫剧制作的结构化剧本。

常见输出包括：

  • 故事背景与核心冲突
  • 角色身份、动机和人物关系
  • 分集大纲
  • 场景编号与场景说明
  • 人物动作和对白
  • 每集开头的吸引点
  • 结尾悬念或下一集钩子

它的价值不是单纯“把文字写长”，而是提前解决剧情节奏问题。

很多 AI 漫剧画面并不差，但播放数据不理想，常见原因是开头进入剧情太慢、冲突不明确，或者每集结尾缺少继续观看的理由。

因此，剧本生成后仍然需要人工检查：

  • 前几秒是否出现核心事件
  • 主角目标是否明确
  • 冲突是否能够通过画面表现
  • 对白是否过多
  • 每个场景是否有存在的必要

二、图像资产 Skill

图像资产 Skill 会从剧本中提取需要反复使用的视觉元素，例如：

  • 主要角色
  • 次要角色
  • 服装造型
  • 场景
  • 道具
  • 交通工具
  • 特殊物品
  • 关键视觉符号

随后，它会为每项资产生成结构化说明和图像提示词。

一份实用的角色资产档案，至少应包含：

  • 年龄范围
  • 脸型与五官特征
  • 发型和发色
  • 身材与体态
  • 服装款式、颜色和材质
  • 常用表情
  • 正面、侧面和背面参考
  • 中文与英文提示词
  • 不允许变化的角色特征

这一步的重点是解决**角色一致性**。

同一个人物在不同镜头中出现时，应尽量复用相同的角色描述和参考图，而不是每次重新生成一套提示词。否则容易出现脸型、发型、服装颜色和年龄不断变化的问题。

三、专业分镜 Skill

分镜 Skill 负责把剧本转换成可以直接执行的镜头清单。

它通常会为每个镜头标注：

  • 镜头编号
  • 场景与时间
  • 出场人物
  • 景别
  • 摄影机角度
  • 人物位置
  • 人物动作
  • 表情变化
  • 灯光与色调
  • 镜头运动
  • 台词或旁白
  • 建议时长
  • 首帧或关键帧提示词

例如，剧本中只有一句：

主角发现桌上的合同被人替换。

分镜需要进一步明确：

  • 先用近景展示主角翻开合同
  • 再切换到合同签名位置的特写
  • 主角手指停顿，表情从疑惑变为警觉
  • 镜头缓慢推进
  • 背景声音逐渐减弱
  • 最后切到门外模糊的人影

只有完成这样的镜头拆解，图像模型和视频模型才能获得更明确的执行信息。

三类 Skill 如何组成完整工作流

一套基础的 AI 漫剧生产流程可以按照下面的顺序执行：

第一步：导入故事

输入小说章节、故事大纲或原创创意，明确：

  • 视频类型
  • 目标平台
  • 单集时长
  • 画面比例
  • 目标观众
  • 视觉风格

第二步：生成分集剧本

使用剧本 Skill 输出分集大纲和单集剧本，并人工确认剧情逻辑、冲突和结尾钩子。

第三步：建立资产库

使用资产 Skill 提取角色、场景和道具，先生成角色参考图或三视图。

资产确认后再进入批量分镜阶段，避免后期不断返工。

第四步：生成分镜

使用分镜 Skill 将剧本拆解为逐镜头表格，并生成每个镜头的关键帧提示词。

第五步：生成图片和视频

把已经确认的角色参考图、场景资产和分镜提示词交给图像或视频模型。

生成过程中应优先检查：

  • 人物是否一致
  • 服装是否变化
  • 场景空间是否连续
  • 人物动作能否衔接
  • 镜头景别是否过于重复

使用 Skill 不代表可以完全自动化

Skill 的作用是把经验和制作规则整理成可重复执行的流程，但它不能自动保证作品质量。

实际制作中仍然需要人工完成：

  • 判断故事是否值得制作
  • 修改生硬对白
  • 选择最终角色形象
  • 检查人物和场景一致性
  • 筛选生成结果
  • 控制节奏、配音和音乐
  • 处理版权及人物肖像风险

更准确地说，Skill 能够减少重复整理和提示词编写工作，让创作者把更多时间放在剧情判断和成片质量上。

相关开源项目

1. Drama Skills

一套面向 AI 短剧和漫剧制作的 Skills，覆盖故事开发、剧本、资产、图片提示词、分镜、视频提示词和独立审查。

GitHub：

https://github.com/worldwonderer/drama-skills

该项目适配 Claude Code 和 Codex。目前主要输出结构化文本、资产说明和提示词，不会直接调用图片或视频生成服务。

2. 山音超级编剧大师

用于短片、电影和多集剧集创作的编剧 Skill，覆盖人物设计、结构大纲、场景拆解和完整剧本。

GitHub：

https://github.com/Shanyin-ai/shanyin-screenwriting-master

3. 山音导演大师

负责导演定调、节奏规划、剧本调整和专业分镜拆解，可输出标准分镜表。

GitHub：

https://github.com/Shanyin-ai/shanyin-director-master

总结

AI 漫剧制作的关键，不是一次生成多少张图片，而是能否建立稳定的生产流程。

剧本 Skill 负责解决故事和节奏问题，资产 Skill 负责保持人物与场景一致，分镜 Skill 负责把文字转换为可执行的镜头。

将这三类 Skill 串联起来，可以明显减少重复工作，但最终作品是否好看，仍然取决于创作者对剧情、画面和节奏的判断。
